# Purify X

适用于 Firefox/Chrome 的 userscript。在 `x.com` 和 `twitter.com` 的推文详情页
过滤垃圾回复，并可选在时间线隐藏账号名单内容或高置信推广、在账号主页隐藏
高置信推广。

当前版本：`2.7.10`

## 安装与更新

1. 安装 Violentmonkey（推荐）或 Tampermonkey。
2. 打开 [Purify X 安装地址](https://raw.githubusercontent.com/longmeidao/purify-x/main/purify-x.user.js)。
3. 在 userscript 管理器中确认安装，然后刷新 X。

脚本会通过同一 GitHub 地址自动检查更新。更新旧版本时直接覆盖原脚本，不要同时启用
多个副本。个人名单、关键词、订阅和 AI 设置保存在 userscript 管理器的本地存储中，
覆盖代码不会清除；既有 `xps-*` 存储键和旧公开 API 别名继续保留升级兼容。

## 日常使用

- 被过滤的内容会缩成带评分和原因的占位行；连续命中会合并，但不会把 X 的
  `cellInnerDiv` 压成零高度，以免破坏虚拟列表滚动。
- “恢复此条”只恢复当前内容；“永久放行”把作者加入本地放行名单。
- 账号名单类隐藏可以“加入本地屏蔽”；推广内容按单条帖子判定，不提供该操作，
  避免把偶尔发布广告的正常账号整体屏蔽。
- 显示名旁的“低”“广”“疑”分别表示账号名单、推广内容和其他可疑内容；完整原因
  保留在悬浮提示与无障碍名称中。“放”可直接永久放行该账号。
- 右下角盾牌显示隐藏数量。左键临时显示或重新隐藏全部内容，右键打开设置；也可以
  从 userscript 管理器菜单打开设置。
- 进入账号 Media 页面时会优先选择 Photos；用户手动切换后不再干预。

## 设置面板

- **公开来源**：分别启用或关闭 MXGA、Twitter Block Porn 与 TweetGuard，并查看
  同步时间、数量和错误。
- **过滤与显示**：账号名单时间线过滤默认关闭；高置信推广过滤默认开启，并覆盖
  Home、账号主页 Posts/Replies 等列表。MXGA 申诉入口和右栏 Premium/热门话题
  隐藏均可独立控制。
- **永远放行账号**：每行一个 `@handle`，优先级高于本地屏蔽、订阅、公开名单、
  内容规则和 AI。
- **本地屏蔽账号**：每行一个 `@handle`，只影响当前浏览器，不调用 X 拉黑接口。
- **自定义强屏蔽词**：每行一个规则。支持中文短语、ASCII token、`@handle`、
  `#hashtag` 和 `domain:bad.example`；域名规则只检查页面可见文字。
- **自定义订阅地址**：每行一个 HTTPS 地址，每 6 小时检查一次。服务器支持 ETag 时
  会使用条件请求；失败时保留上一次有效缓存。
- **可选 AI 灰区判断**：默认关闭，可配置 OpenAI 兼容 endpoint、模型、API Key 和
  每日调用上限。

### 导入与订阅格式

本地设置可以导入或导出为 JSON，仓库中的 `purify-x-local-list.example.json` 可作
示例：

```json
{
  "schema": 1,
  "block": ["spam_account"],
  "allow": ["never_hide_me"],
  "keywords": ["自定义推广词组"],
  "subscriptions": [
    "https://raw.githubusercontent.com/example/repo/main/x-list.json"
  ],
  "builtInSources": [
    "mxga",
    "twitterBlockPorn",
    "tweetGuard"
  ],
  "builtInSourceCatalogVersion": 2
}
```

远程自定义订阅只接受 Purify X JSON v1，并只读取 `block`、`allow`、`keywords`：

```json
{
  "schema": 1,
  "block": ["spam_handle"],
  "allow": ["false_positive"],
  "keywords": ["高置信度垃圾词组"]
}
```

自定义订阅可以使用任意 HTTPS 地址，因此脚本声明了通配 `@connect`；它只会请求
启用的公开来源和用户主动填写的地址，并使用匿名请求，不发送 X Cookie。

## 内容识别与作用范围

Purify X 综合账号名单、正文、昵称、链接、页面结构和同一回复区内的行为证据评分，
不会因为单个普通词或单条弱特征直接隐藏内容。主要识别：

- 色情引流、诈骗、联系方式、主页导流和常见批量模板。
- 拆字、插空、零宽字符、随机字母和句中 emoji 等规避形式。
- 同账号重复低信息回复、跨账号复用模板和集中出现的协调式回复。
- 自定义关键词、订阅规则和公开账号名单。
- “Telegram 外链 + 推广话术”。
- “限制回复 + 普通外链 + 推广话术”。
- “限制回复 + Telegram 外链”。

链接可以出现在正文，也可以只显示在正文下方的 X 外链预览卡片；引用推文中的链接
不会算作外层帖子的内容证据。普通讨论同城配送、上门维修或免费资源，不会仅凭这些
常用词直接隐藏。

推文详情页的主贴和主贴作者自己的续写回复始终显示，只过滤其他账号回复。Home、
Explore、搜索、Lists、Communities、书签和通知支持账号名单及推广过滤；账号主页
Posts/Replies 只运行推广过滤。账号名单过滤默认关闭，高置信推广过滤默认开启。

## 账号保护、转推与引用

- 当前登录账号自己的内容直接放行。
- 本地和订阅的永久放行账号优先于所有屏蔽来源。
- 关系暂时无法确认时放行，不冒险隐藏。
- 已关注账号通常放行；只有帖子自身命中上述高置信推广组合时才允许进入评分。
- 转推会同时识别原作者和转推者。转推者是自己、已关注、永久放行或关系未知时，
  整条放行；无法取得转推者时回到既有的原作者判定。
- 引用作者命中名单只能作为外层内容的一条证据，不能绕过外层作者的自己、永久放行
  或关系未知保护；详情页主贴仍始终显示。

关系和身份数据只从当前 X 页面已加载的 DOM/React 数据读取，不调用 X API，也不
遍历或上传关注列表。数字 ID 与 handle 等身份来源冲突时，不采用冲突的公开结果。

## 自动同步的公开来源

- [Make X Great Again（MXGA）](https://github.com/foru17/make-x-great-again)：
  账号名单、社区规则和误杀白名单。
- [Twitter Block Porn](https://github.com/daymade/Twitter-Block-Porn)：
  公开账号名单。
- [TweetGuard](https://github.com/viewer12/tweetguard)：社区正文模板，按低权重证据
  使用，需与其他内容或行为特征组合。

首次运行会下载已启用来源，以后每 6 小时检查更新。同步会校验 schema、字段、账号
格式、条目数和响应大小；格式错误、数量异常或网络失败时保留旧缓存，各来源互不
清空。MXGA 服务不可用时会回退到其 GitHub 镜像。

MXGA 人工确认条目可单独达到隐藏阈值；AI 自动条目必须再结合其他内容或行为证据。
MXGA 白名单和本地永久放行优先于公开黑名单。账号优先按不可变数字 ID 匹配，handle
仅作兼容回退；身份冲突时不采用公开名单结果。

## 可选 AI 判断

AI 默认关闭，只处理本地评分 2–6 分的灰区回复：

1. 自己、已关注保护、永久放行、明显正常和已经达到隐藏阈值的内容不会调用 AI。
2. 只有 AI 明确判为垃圾且置信度至少 90% 才会隐藏；每日默认最多 20 次。
3. 自动学习只接受回复正文中确实存在、长度合格的字面片段，不接受模型生成的正则、
   昵称或账号 ID。
4. 自动规则默认 90 天有效，再次命中续期；用户连续三次恢复由该规则决定隐藏的内容，
   规则会在本地停用。手动规则不会自动过期。

请求只发送当前灰区回复正文、显示昵称、账号 ID、本地评分和原因，不发送页面 URL、
浏览记录、X Cookie 或关注列表。API Key 存在 userscript 管理器本地存储中，不进入
名单导出，但它不是操作系统钥匙串。

endpoint 必须是 HTTPS 的 OpenAI 兼容 Chat Completions 地址；本机
`http://localhost` 和 `http://127.0.0.1` 也允许。AI 不能修改阈值、硬编码规则、
公开名单或放行名单，也不会自动上传学习结果。

## 缓存与滚动

- 名单、订阅、偏好和 AI 状态会先从本地缓存加载，再开始首屏扫描。
- 判定结果最多保存 2,000 条、有效 7 天；规则、名单、阈值或版本变化时自动失效。
- 当前详情页最多保留 500 条已观察回复的纯数据行为记录，切换帖子后清空。
- X 复用虚拟列表节点时，脚本会先释放旧状态，再按状态 ID 恢复缓存结果。
- 增量观察器只补扫受影响的推文；正文、作者或外链预览卡片的文本节点原地更新也会
  触发定向判定，不因点赞数、图片或视频变化反复全页评分。
- 连续隐藏只压缩脚本自己的占位节点，并保留可测量高度，不修改 X 虚拟 cell 的高度。

## 举报、申诉与隐私

- 脚本不会自动举报、拉黑、静音、关注、发帖或上传浏览记录。
- 未启用 AI 时，页面内容判断全部在本地完成。
- “向 MXGA 申诉”只打开预填的 GitHub issue，是否提交由用户决定。
- 导出或提交规则前，应删除私人放行名单、浏览记录和未经人工确认的数据。

脚本使用：

- `GM_getValue` / `GM_setValue`：保存设置、名单和缓存。
- `GM_xmlhttpRequest`：下载公开名单和用户配置的订阅。
- `GM_registerMenuCommand`：提供设置入口。

## 调试

公开调试 API：

```js
__PURIFY_X__.scoreReply("回复正文", "显示昵称", "@handle")
__PURIFY_X__.openSettings()
__PURIFY_X__.localSettings()
await __PURIFY_X__.syncCustomSubscriptions(true)
await __PURIFY_X__.syncRemoteLists(true)
__PURIFY_X__.remoteStatus()
```

全局阈值默认为 `7`。修改阈值属于开发行为，调整后应重新运行全部回归测试。旧的
`__X_REPLY_PURIFIER__` 与 `__X_PORN_SPAM_FILTER__` 仅作为兼容别名保留。
